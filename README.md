# TaskFlow — JavaScript To-Do List

A responsive, client-side task manager demonstrating DOM manipulation, event handling, CRUD operations, filtering and browser localStorage.

## Run
1. Extract the ZIP file.
2. Open `index.html` in a modern browser, or open the folder in VS Code and use Live Server.
3. Add tasks, mark them complete, edit or delete them, and switch between All / Active / Completed.
4. Refresh the page: your tasks remain saved in that browser.

## Files
- `index.html` — semantic application structure
- `style.css` — responsive styling and mobile layout
- `script.js` — task state, CRUD, delegated events, filters and localStorage

## Notes
- Data is stored locally in the current browser under `taskflow-tasks-v1`.
- Clearing browser site data may remove saved tasks.
- No backend or account is required.
